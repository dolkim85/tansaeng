# 배선 가이드 (초보자용)

⚠️ **고전압/펌프/밸브 배선을 확정하기 전에 반드시 두 보드 실물 사진(전원단자, RS485 A/B/GND 라벨, DI1~8 라벨), 유량계 라벨, 밸브/SSR 명판을 먼저 확인하세요.** 이 문서의 핀 번호는 검증된 정보지만, 실물 스크류터미널 라벨은 사진으로 최종 확인이 필요합니다(작업지시서 15번).

## 핀맵 요약 (근거: `docs/hardware-verification.md`)

### 메인 노드 (ESP32-S3-ETH-8DI-8RO)

| 라벨 예상 | 연결 대상 |
|---|---|
| 전원 입력 (스크류터미널) | 7~36V DC (또는 USB-C 5V 보조) |
| RS485 A / B / GND | 팔 노드의 RS485 A / B / GND |
| DI1 (절연입력) | 유량계(YF-B10-S) 신호선 — **24V를 GPIO에 직결하지 말 것, DI1의 절연회로를 통해서만 연결** |
| Ethernet(RJ45) | 공유기 LAN 포트로 케이블 연결 |

### 팔 노드 (ESP32-S3-Relay-6CH)

| 라벨 예상 | 연결 대상 |
|---|---|
| 전원 입력 | 5V/12V (보드 사양에 맞춰 실물 확인) |
| RS485 A / B / GND | 메인 노드의 RS485 A / B / GND (A-A, B-B로 연결, 극성 반대로 연결해도 대개 무응답일 뿐 손상은 없음) |
| CH1 릴레이 접점 | 메인밸브 SSR/전자접촉기 코일 (밸브 자체를 직접 구동하지 말 것) |
| CH2 릴레이 접점 | 포깅밸브 SSR/전자접촉기 코일 |
| CH3 릴레이 접점 | 바이패스밸브 SSR/전자접촉기 코일 |

RS485 종단저항: 배선 길이가 길거나 통신이 불안정하면 보드의 120Ω 종단저항 점퍼를 활성화(양쪽 끝 노드 중 하나 또는 둘 다, 실물 테스트로 판단).

## 처음 전원 넣기 전 점검표

- [ ] 메인/팔 노드 전원 극성 확인 (역결선 시 보드 손상 가능)
- [ ] RS485 A-A, B-B로 연결(교차 연결 안 됐는지)
- [ ] 릴레이 접점에 실제 밸브가 아니라 **LED 또는 저전압 테스트 부하**만 연결된 상태로 첫 전원 (작업지시서 12번 5단계)
- [ ] 유량계 신호선이 DI1에 연결됐고, 24V가 다른 GPIO나 메인 로직 전원에 직결되지 않았는지
- [ ] 이더넷 케이블이 실제로 인터넷 되는 공유기 포트에 꽂혀있는지
- [ ] 기존 WiFi ESP32(ctlr-0004)를 **버리지 않고** 옆에 대기시켜뒀는지 (아래 전환 절차 참고)

## 현장 전환 및 롤백 절차 (실제 밸브 배선 시 반드시 따를 것)

MQTT 토픽이 기존과 완전히 동일하므로, 서버/UI는 어느 쪽 하드웨어가 붙어있든 신경 쓰지 않습니다. "한 번에 교체"가 아니라 **되돌릴 수 있는 단계적 전환**으로 진행합니다.

**1단계 — 책상 위 벤치 테스트**
실제 밸브 연결 전, 두 새 보드만 따로 놓고 이더넷+RS485+MQTT 통신을 확인합니다. 릴레이는 LED나 멀티미터로만 확인합니다. 이 단계는 실패해도 농장 운영에 영향이 없습니다.

**2단계 — 병행 배치**
1. 기존 WiFi ESP32(`ctlr-0004`)의 전원을 뽑아 옆에 대기시킵니다(폐기 금지).
2. 새 시스템을 실제 밸브 배선에 연결합니다.
3. **MANUAL 모드로만** 먼저 테스트합니다(AUTO는 아직 켜지 않음). 웹 UI에서 밸브 ON/OFF를 눌러 실제로 열리고 닫히는지, 90초 안전타임아웃이 동작하는지 확인합니다.
4. 이 단계는 반드시 사람이 현장에서 지켜보면서 진행합니다(무인 방치 금지).

**3단계 — 문제 발생 시 즉시 롤백**
새 보드 전원을 내리고, 기존 WiFi ESP32 전원을 다시 연결합니다. 밸브 커넥터가 호환되도록 미리 배선해두면 몇 분 안에 원상복구됩니다. 서버/UI는 아무것도 바꿀 필요가 없습니다(토픽이 동일하므로).

**4단계 — 안정 확인 후에만 AUTO 전환**
MANUAL로 최소 며칠간 문제없이 동작하는 것을 확인한 뒤에만 AUTO를 켭니다.

**5단계 — 로컬재생 기능은 가장 마지막에**
구역A 로컬재생(`localReplay`, 인터넷 끊김 시 자동재생)은 기본 유선 명령 실행이 충분히 안정적임을 확인한 뒤에 별도로 검증합니다. 한 번에 여러 새 기능을 동시에 켜면 문제가 생겼을 때 원인 파악이 어렵습니다.

**추가 권장**: 가능하면 배관에 전자밸브와 별개인 수동 개폐 밸브를 하나 더 두면, 전자적으로 문제가 생겨도 물리적으로 막을 수 있는 최후의 안전장치가 됩니다.
